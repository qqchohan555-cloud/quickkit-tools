# PixelNest Wallpapers

A single-file responsive wallpaper discovery page built for GitHub Pages.

## Features
- Responsive dark UI with hero section and editorial featured art
- Search by title, category, tags, and resolution
- Category filtering, sorting, and a preview modal
- Save/favorite wallpapers in browser local storage
- Links to related Wallpaperflare searches for every wallpaper
- No build step, package installation, API key, or assets folder required

## Location
The site is at `wallpaper-world/index.html` so it does not replace the existing QuickKit Tools homepage.

Expected site URL (when GitHub Pages is enabled for this repository):
https://qqchohan555-cloud.github.io/quickkit-tools/wallpaper-world/

If the URL does not load, open **Settings → Pages** in this repository and set **Build and deployment → Deploy from a branch → main → /(root)**, then save.

## Image and rights note
The preview photos are served from Unsplash URLs for the demo. The buttons link to Wallpaperflare search results to help visitors find wallpaper pages there. Wallpaperflare's terms prohibit copying or mirroring its site without permission; only embed or redistribute Wallpaperflare assets after confirming you have the rights or permission. Check each image's license and source terms before commercial use.

## Customize
Edit the `wallpapers` array in `index.html` to change titles, tags, categories, image IDs, or resolution labels. Replace demo previews with images you have permission to use.
